e-POWERモニター

セレナ e-POWER C28 の Android Auto 画面に速度・バッテリー残量を自前描画するアプリ（開発版）。

APK をダウンロード（v0.1 debug）

Pixel 7 でのインストール手順

  1. このページを Pixel 7 の Chrome で開き、上のボタンで APK をダウンロードする。
  2. ダウンロード通知から APK を開く。「不明なアプリのインストール」を求められたら Chrome（またはファイル）に許可を与える。
  3. インストールを実行する。ホーム画面にアイコンは出ない（車の画面専用アプリのため）。

Android Auto 側の準備（初回のみ）

  1. 設定 → デバイス情報 → ビルド番号を7回タップ（開発者向けオプションの有効化）。
  2. 設定 → アプリ → Android Auto → 「追加の設定」で Android Auto の設定画面を開く。
  3. 最下部の「バージョンと権限情報」を10回タップして開発者モードを解錠する。
  4. 右上メニュー → 開発者向け設定 → 「提供元不明のアプリ」を有効化する（英語表記では Unknown sources）。

この状態で車に接続すると、車の画面のアプリ一覧に「e-POWERモニター」が現れる。
